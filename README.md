# Cyber OSINT — Threat Intelligence Platform

A professional cybersecurity threat intelligence tool for investigating IP addresses and URLs.

## Features
- IP & URL/Domain reputation analysis
- VirusTotal vendor breakdown
- Reverse IP & Reverse DNS lookup
- Passive DNS history
- SSL/TLS certificate enumeration
- WHOIS risk analysis
- ASN reputation flagging
- 12+ OSINT platforms (AbuseIPDB, Shodan, GreyNoise, AlienVault OTX, etc.)
- Sandbox tools (ANY.RUN, Hybrid Analysis, Joe Sandbox, Browserling)
- Symantec SiteReview categorization
- Session history & Export (JSON/PDF)
- Matrix rain cybersecurity backdrop

## Usage
Visit the live site and enter any IP address or domain to begin investigation.
